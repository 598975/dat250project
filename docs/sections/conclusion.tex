\section{Conclusions}
\label{sec:conclusions}

Concludes on the project, including the technology, its maturity,
learning curve, and quality of the documentation. \newline

The concluded project is a well functioning demo of the application described in the problem description. The various different technologies function well together without any conflicts. The result of the project is not a complete and finished application, and it would require additional features and changes to reach this point, but it still manages to showcase the strengths of the chosen technologies.

Both the chosen technology EF Core and framework ASP.NET Core have been simple both to learn and work with. The official documentation is thorough and extensive \cite{EFoverview}, and the experiments in section \ref{sec:technology} showcase the development speed the framework allows. The syntax of the framework and reduction in boilerplate code has lead to code that is easy to understand and readable.
