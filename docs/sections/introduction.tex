\section{Introduction}
\label{sec:introduction}

This project has aimed to create a full-stack prototype of a poll system. The aim of the prototype was to create a system that is functional and secure while meeting key requirements:

\begin{itemize} 
    \item A web-based interface for users and a REST API for external interaction. 
    \item Secure access through user authentication. 
    \item A relational database for structured data storage. 
\end{itemize}


The system is containerized using Docker and hosted on Docker Hub https://hub.docker.com/r/h598970/dat250_messaging and https://hub.docker.com/r/h598970/dat250_api. PostgreSQL manages structured data storage, while MongoDB handles more flexible, unstructured data. 
The back end is built with .NET Core, and the front end uses a single-page application framework.

he results show that the system meets the project goals. It provides both a user-friendly interface and a programmatic API, manages data securely, and integrates the selected technologies effectively.
