\section{Introduction}
\label{sec:introduction}

This project has aimed to create a full-stack prototype of a poll system. The aim of the prototype was to create a system that is functional and secure while meeting key requirements:

\begin{itemize} 
    \item A web-based interface for users and a REST API for external interaction. 
    \item Secure access through user authentication. 
    \item A relational database for structured data storage. 
\end{itemize}


The system is containerized using Docker and hosted on Docker Hub \cite{noauthor_h598970dat250_api_nodate} \cite{noauthor_h598970dat250_messaging_nodate}. 
PostgreSQL manages structured data storage, while MongoDB handles more flexible, unstructured data. 
The back end is built with .NET Core, and the front end uses a single-page application framework.\\
The results show that the system meets the project goals.
It provides both an interface and a REST API, manages data securely, and integrates the selected technologies. \\
The rest of this report is organized as follows: \\
Section~\ref{sec:design} describes the system's design, including the architecture and use cases. \\
Section~\ref{sec:technology} outlines the selected technologies and their roles in the project. \\
Section~\ref{sec:implementation} explains the implementation process, and Section~\ref{sec:conclusions} discusses the outcomes and areas for improvement.\\
